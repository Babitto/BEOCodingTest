# Project Name
-- Multi-Portal Job Posting System

## Description
"This project provides a RESTful API for managing job postings across multiple job portals"


## Setup Instructions

### Prerequisites
- Node.js (v16 or higher)
- npm (v8 or higher)
- A database MSSQL (Sequelize ORM)
- A code editor like VS Code


##  Environment variables.
-  Environment variables stored in .env file


### Steps to Install Dependencies

1. Clone the repository: git clone https://github.com/Babitto/BEOCodingTest.git

2. npm install - for installing dependencies

## start the application

    node index.js
